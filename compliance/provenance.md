# Source provenance

All application, test, documentation, schema and original mechanical source in this repository was created for OpenPatrol. No upstream source files are vendored. External projects are integrated as separately installed packages or containers and retain their own licences.

Before a tagged release, resolve container tags to immutable digests, generate an SPDX or CycloneDX SBOM from the built images, download the official CERN-OHL-P-2.0 text for the hardware archive, and record model/weight licences separately from detector code.
