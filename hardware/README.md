# OpenPatrol One hardware

This directory contains parametric OpenSCAD source for the base and universal payload plate, an India-oriented BOM and the electrical safety specification. Dimensions are a starting point for a 2WD/caster mule, not fabrication certification. Export STL/DXF after selecting real motors, battery and enclosure; verify every hole pattern against supplier drawings.

No generated STEP is included because converting guessed motor envelopes into a beautiful solid would be false precision. The first physical builder must replace provisional envelopes with supplier-controlled dimensions and publish the revision plus test evidence.
