# OpenPatrol hardware

This directory contains parametric OpenSCAD source for a 2WD/caster mule, the proposed four-wheel Rover One, the three-wheel TriScout and a universal payload plate, plus an India-oriented BOM and electrical safety specification. These are editable prototype layouts, not fabrication certification. See [`docs/hardware-platforms.md`](../docs/hardware-platforms.md) for the maturity and upstream-integration matrix.

No generated STEP is included because converting guessed motor envelopes into a beautiful solid would be false precision. The first physical builder must replace provisional envelopes with supplier-controlled dimensions and publish the revision plus test evidence.
